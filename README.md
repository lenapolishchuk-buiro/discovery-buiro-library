# Бібліотека військових досліджень 2020–2026 · Discovery Buiro

Бібліотека емпіричних досліджень про військовий рекрутинг і військові комунікації (Україна та світ): 412 досліджень, пошук запитанням, дерево тем, міжнародний досвід, джерела.

**Сайт:** https://lenapolishchuk-buiro.github.io/discovery-buiro-library/

Архів актуальний станом на 7 листопада 2026 року.
Періодичність оновлення: раз на квартал.

Цю бібліотеку досліджень Discovery Buiro підготувала як подарунок учасникам навчання з військових комунікацій.

Discovery Buiro не є автором досліджень у бібліотеці. Усі звіти підготували зовнішні організації — їхні назви, автори й посилання на першоджерела збережено в кожній картці. Discovery Buiro зібрало, перевірило, впорядкувало та проіндексувало ці матеріали.

`index.html` — уся бібліотека одним файлом (дані, стилі, шрифти вбудовано); працює і локально, без інтернету.
